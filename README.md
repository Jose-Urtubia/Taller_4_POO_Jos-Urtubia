##### Este proyecto consiste en un simulador para el ramo de POO, donde se gestiona una colección de cartas pokemon. El sistema permite administrar cartas y sus distintas variantes (Energy, Item, Pokemon y Supporter), calculando puntuaciones específicas según el tipo y mostrado gracias a un sistema GUI.
